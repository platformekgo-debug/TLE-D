# Terminale D — Cours et Sujets

Application Android hors ligne à l'usage des élèves de Terminale D en Côte d'Ivoire.

**298 documents embarqués** : 170 cours et 128 sujets d'annales, tous consultables sans
connexion. L'application ne contient aucune publicité et n'envoie aucune donnée.

## Fonctionnalités

- **Esther**, l'assistante : elle a lu les 298 documents et s'appuie sur les passages
  retrouvés dans les cours pour répondre, avec les formules composées en LaTeX.
- **Le tuteur, page par page** : vous ouvrez un cours, vous allez à la page qui vous
  intéresse, vous ouvrez Esther — elle travaille alors sur *cette page*, à votre demande.
  Trois boutons : expliquer la page, donner des exercices sur la page, puis le corrigé.
- **Sommaire cliquable** à l'intérieur des documents, pour aller droit à une leçon.
- **Recherche** dans tout le corpus, et reconnaissance de texte sur les documents numérisés.
- **Mise à jour automatique** : l'application prévient quand une version plus récente
  existe, et ne télécharge jamais rien sans votre accord.

## Installation

Téléchargez la dernière APK depuis
[la page des releases](https://github.com/platformekgo-debug/TLE-D/releases), puis autorisez
l'installation depuis une source inconnue si le téléphone le demande.

## Fichier version.json

Ce fichier décrit la dernière version publiée. L'application installée le consulte pour
savoir si elle doit proposer une mise à jour. Il est régénéré par
`python3 tools/maj_version.py`.
